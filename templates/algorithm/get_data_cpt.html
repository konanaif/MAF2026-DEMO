Causal Path Tracing Demo

Causal Path Tracing traces the internal path a language model (pythia-14m) uses to answer a factual statement from the known_1000 dataset, keeps only that path and checks whether the answer survives.

  • 모델: EleutherAI/pythia-14m
  • 데이터: known_1000 (1,209 statements, index 0~1208)
  • 참고: 모델이 원래 답을 틀리는 샘플은 추적에서 제외되어 결과 표에 나타나지 않습니다. 소요 시간은 GPU 에 따라 다릅니다.
