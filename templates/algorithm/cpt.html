{% endblock %} {% block body_content %} {% if status == "running" %}{% endif %} Causal Path Tracing is an algorithm for causally tracing the internal pathways of a Transformer-based model's answer generation. The algorithm explores the causal path for each sample's model decision within a pretrained Transformer, then keeps only the nodes on that path (intervening on every other node) and checks whether the model still makes the same decision.
- path_node_ratio(선택된 경로 비율): the share of path nodes (attention and MLP blocks, summed over layers) that the traced causal path keeps. Lower means a sparser explanation: 0.76 means 76% of the nodes were needed to explain the decision.
- decision_kept_ratio(경로만 남겼을 때 원래 예측 유지율): the share of samples whose original decision is preserved when only the causal path is kept (the Hit Rate of the original paper). 1.0 means every sample kept its decision.
